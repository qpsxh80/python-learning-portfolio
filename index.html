학습 목표: 변수의 값을 바꾸고 결과를 설명하기

사례 1 · 변수 값을 바꿔 출력 비교하기

Situation

Python Chapter 1에서 변수에 값을 저장하고 출력하는 법을 배우고 있었다.

Task

변수 x의 값만 바꿔도 같은 계산식의 결과가 달라지는지 확인하려 했다.

Action

x = 3으로 정하고 print(x + 2)를 실행했다. AI에게 대입과 출력의 차이를 물은 뒤, x = 8로 바꾸고 파일 전체를 다시 실행했다.

Result

출력이 5에서 10으로 바뀌었다. 첫 줄의 값을 바꾸면 뒤의 계산에 그 값이 쓰인다는 것을 확인했다.
